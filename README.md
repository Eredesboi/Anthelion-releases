# Anthelion — versions

Les installeurs d'[Anthelion](https://anthelion.applicationdev.workers.dev), lus par la mise à jour automatique de l'app. Le code n'est pas dans ce dépôt.

## Ce que contient une version

- **Windows** : `Anthelion-Setup-<version>.exe`
- **Linux** : `.deb` et `.AppImage`
- **Mac** (Apple Silicon) : `.dmg`
- les fichiers `latest*.yml`, que l'app lit pour se mettre à jour toute seule.

## À savoir

- Ce sont des **versions de développement** (0.0.x), publiées au fil de l'eau.
- Les installeurs **ne sont pas signés** : le système peut avertir à la première ouverture.
- Une fois installé, Anthelion se met à jour seul.

Les nouveautés de chaque version sont dans les notes de la version. La documentation est sur le [site](https://anthelion.applicationdev.workers.dev).
